# 数值算子三件套（定义 / 复杂度 / 误差界）

> 每一个数值算子在这里交齐三件套：**定义**（输入域、输出域、代数性质）、**复杂度**（紧界 + 达到界的构造）、**误差界**（前向误差或实测容差，指向钉住它的测试）。位级一致性单独列一栏，指向用 `to_bits()` 逐位对拍的用例。
>
> 符号：`u` 为单元舍入（f32 `u = 2^-24 ≈ 5.96e-8`）；`γ_n = n·u / (1 − n·u)`。表中「实测界」是测试里真实 assert 的容差，不是外推值。

| **GEMV f32 decode**（`crates/nn`） | `y[M] = W[M,K]·x[K]`（`K=4096` 权重侧）；每输出一个长内积。 | 时间 `Θ(MK)`；**带宽界**：算术强度 `2/(4·1)=0.5 FLOP/byte`，落在 roofline 的 DRAM 区。2026-11-22 / Apple M5 Pro（18 核、单线程）同会话交替 **6 `40.0` → 行并行版 `66.4`（+66%）。`COLS`（一次并行几行）扫 2/4/8 → `55.1/49.5/44.7`（每多一条行流就多一条 DRAM 预取流，与 `x` 争抢，**MLP 惩罚**）；`COLS=3` → `30.0`（非 2 的幂，LLVM 放弃向量化）。`SPAN` 扫 8/16/32/64 → `62–69/63–69/56–60/50.7`；`DEPTH`（每行独立累加链）1→2 增益 +3.5%（`COLS=2` 只有 2 条链，喂不满 4 拍乘加延迟）。最终 `COLS=2 / SPAN=8 / DEPTH=2`。**A2 端口百分比（结论，不是 GF/s）**：取数端口 2×16 B/周期 = 32 B/周期；`COLS=2` 时每 64 B 权重恰好需 4 条权重 load + 2 条 `x` load（`x` 由 2 行摊薄）= 6 条 → 3 周期/64 B → 有效 **21.33 B/周期**。实测中值 80.3%（= 66.4 GiB/s 口径）在 3 周期/64 B 下反推主频 `3.36 GHz`，而 82.4 GiB/s 的 DRAM 上限折 **26.3 B/周期**，`21.33/26.3 = 81.1%` 与实测中值 80.3% 吻合 ⇒ **实现已达自身形状的端口界 99%**，缺口全部来自 `x` 占掉的 1/3 取数槽。**A3 三个可核对的数**：保守值 `80.3%`（区间下界 78.6%）；下界 floor `82.4 GiB/s`（单线程 64 MiB 读上限，本机口径）；代价——要到 85% 需 `≤2.86 周期/64 B`，只能把 `x` 槽摊到 4 行（`COLS=4`：5 条 load → 25.6 B/周期 ≈ 97% 的 DRAM），但那条路径实测 **`57.5 GiB/s`**（−14%），即「关掉最后 4.4 点」的代价高于收益。不用软件预取绕开：`prefetch` 是 `unsafe`，而本仓 `unsafe` 只许留在单一岛（N8/M3），不为 4 点指标开第二座岛。故 K9 以 **80.3% + 上式端口界** 登记为红项（门槛 85%，未达 4.7 点），不靠放宽阈值转绿（F4）。 ## 位级一致性（K12）覆盖

逐位对拍（`assert_eq!(x.to_bits(), y.to_bits())`）已覆盖：`crates/algorithm/tests/spike_tests.rs`（INT8 脉冲 LIF 整数累加 + 代理梯度），`crates/dtype/tests/{dtype,qtype,mxtype}_tests.rs`（块量化编码），`crates/tensor/tests/tensor_tests.rs`。这些是「整数语义 / 编码」路径，天然可逐位；浮点 SIMD 求和路径（GEMM/GEMV/softmax）因重排顺序不承诺逐位相等，按 A1 以 `γ_n` 界 + 实测容差（上表）为契约，不造假逐位。

## 开口（仍未闭合，及闭合前提）

1. **GEMV 的逐位对拍在数学上不可得**：`dense_dot` 有 `const LANES: usize = 16` 条独立累加链 + `as_chunks::<LANES>()`，
   求和顺序与顺序标量不同，浮点加法不结合，故「逐位相等」不是可达目标。按 A1 的另一半改为钉住 ulp 上界，
   已闭合（实测 2.6 ulp，见上表）。**同时发现一处假证据**：`gemv::reference` 内部调的正是 `F::forward`
   （`gemv/shape.rs` 的 `run`），所以旧测试 `forward_matches_the_scalar_reference_on_the_deterministic_sample`
   是内核跟自己比（F6），它证明不了任何与独立参考的一致性；已由上表的 f64 参考取代，旧断言保留但不再算证据。
2. **浮点求和路径逐位**：GEMM/GEMV/softmax 的 SIMD 路径与顺序标量参考**不逐位相等**（求和重排）；已按 A1 用 `γ_n` 界 + 测试容差钉住，不做位级承诺。闭合前提 = 把累加器固定为顺序标量（牺牲峰值，与本指令 K7/K8 冲突）。
3. **Winograd / Strassen 未采用**：Conv 只有 direct/im2col，无 Winograd 误差界可交；闭合前提 = 引入 Winograd 路径后补。
